# Babou

Application mobile d'apprentissage du fiqh, avec un espace utilisateur et un espace administrateur.

## Structure du projet

- `apps/mobile/` — application mobile utilisateur (React Native + Expo)
- `apps/admin/` — interface web d'administration
- `packages/shared-types/` — définitions de données partagées entre les deux
- `backend/` — réservé pour le backend (choisi à une étape ultérieure)
- `docs/` — documentation du projet (décisions, glossaire, feuille de route)
