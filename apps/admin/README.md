# apps/admin — dossier non utilisé

Une interface web d'administration séparée était prévue ici. Elle n'a pas été
construite : l'administration vit dans l'application elle-même
(`apps/mobile/src/app/admin/`), réservée aux comptes administrateurs.

L'application tournant aussi sur le web, l'administration reste accessible au
clavier depuis un navigateur — sans second code à maintenir.

Voir la décision du 2026-07-25 dans `docs/decisions.md`.
