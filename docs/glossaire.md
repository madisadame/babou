# Glossaire

- **Livre** : ensemble de chapitres traitant d'un thème du fiqh.
- **Chapitre** : unité de contenu composée d'une vidéo de cours et d'un test.
- **Vidéo de cours** : vidéo hébergée en ligne (pas dans l'app), associée à un chapitre.
- **Test** : série de questions tirées aléatoirement pour vérifier la compréhension d'un chapitre.
- **Question** : contient un énoncé, plusieurs choix de réponses, une bonne réponse, et une explication (écrite et/ou audio).
- **Score** : résultat obtenu à un test.
- **Pourcentage de maîtrise** : indicateur de progression de l'utilisateur sur un chapitre ou un livre.
- **Progression** : suivi dans le temps de l'avancement de l'utilisateur dans les livres/chapitres.
- **Contenu payant** : contenu débloqué après un achat unique.
- **Espace administrateur** : interface web privée réservée à la gestion du contenu (livres, chapitres, questions...).
